# W1 — Mistake-review navigation (MAJOR)

**Finding 1.** Cold-load `/mistakes` → Back ping-pongs `/mistakes ↔ /stats` forever, never reaching Home.

**Root cause (verified, not assumed):** `src/screens/CategoryListScreen.jsx:62` sets `onBack={() => go('stats')}`. `go()` **pushes** a history entry (`App.jsx:95`), while `StatsScreen.jsx:89` uses the real `onBack={goBack}` → `window.history.back()` (`App.jsx:110-112`). So: cold `/mistakes` → Back *pushes* `/stats` → Back *pops* to `/mistakes` → Back *pushes* `/stats`… forever.

**The fix pattern already exists in this codebase.** `src/screens/MistakeDetailScreen.jsx:174-177` solves the identical bug class — its comment explicitly names it "the mistake -> game -> mistake cycle bug" — by gating on a **session-only** nav param:

```js
function handleBack() {
  if (!mistakeContext && !mistakeSource) { go('home'); return; }
  goBack();
}
```

Cold permalink → no context → `go('home')` (one press to Home). In-app → `goBack()` pops correctly. This works because `urlMapping.js` gives `/mistakes` `paramNames: []`, so nav params are never URL-encoded and are absent by construction on a cold load. Apply the same pattern. Do **not** invent a new mechanism.

# W2 — Lesson content localization (MAJOR) — D1

**Findings 2 (Batch D) / F-1 (Batch F).** All 13 lessons render English body text in Spanish mode: the Spanish learner gets an English course behind a Spanish shell. This is the single biggest gap in the run.

**Scope (verified at source):** ~6,860 translatable words across 13 files, in exactly **5 field paths**:

| Path | Notes |
|---|---|
| `.title` | **already** localized via `t('lesson.<id>.title', {defaultValue})` — see warning below |
| `.slides[].coachMessages[].text` | the only field with a generated `audio` sibling |
| `.slides[].legendItems[].label` | e.g. `"Threat square (the winning move)"` |
| `.slides[].infoProse` | single paragraph string |
| `.socratic.goalPrompt` + `.confirmationChallenges[].goalPrompt` | e.g. `"Find the winning move."` |

Non-translatable (do NOT touch): `id`, `free`, `order`, `userPerspective`, `movestring`, `boardSpec`, `overlays[]` (`{c,r,type}` — **has no label field**; labels live only in `legendItems`), `confirmationCategory/Count`, challenge board data, `socratic._boardInstructions` (authoring note, never rendered).

**Four traps this workstream must respect:**
1. **Title double-source.** `en.json`/`es.json` already carry `lesson.<id>.title` for all 13 (already voseo, e.g. `"Bloqueá Antes de Construir"`), and `ConceptScreen.jsx:137` / `SagaScreen.jsx:113` / `SocraticScreen.jsx:151-164` read them with `defaultValue: lesson.title`. The i18n key **wins**. Do **not** add `title_es` — it would create a second, silently-losing source. Leave titles alone.
2. **Audio is hash-of-text keyed and language-blind.** `lessonAudio.js#hashMessageText` = `sha256(text).slice(0,16)`; `ttsProvider.synthesize(text)` takes **no lang/voice arg** — unlike `scripts/generate-tts.js`, which already solved per-locale with `audioDirForLang` + per-locale registries. Spanish text hashes to *distinct* filenames, so files won't collide in the flat `public/audio/lessons/` dir — but the voice must be right.
3. **`pruneOrphanedLessonAudio` will delete every Spanish clip** unless taught about `_es` fields — it deletes any `*.mp3` not referenced by a lesson.
4. `getLesson()` has no locale seam at all, and `GET /api/lessons/:id` never reads `req.locale` — but `localeMiddleware` already parses and whitelists `en`/`es` into `req.locale`. No new plumbing needed.

> **Sizing note:** W2 is by far the largest workstream (~7k words of translation + a loader seam + a TTS seam + an offline script). If it must ship separately, split it out as its own epic. Nothing in W3–W11 depends on it.

In `connect-four/server/lessonLoader.js`, add:

```js
// QA 2026-07-15 finding #2 / decision D1. Spanish lesson text lives in `_es` sibling
// fields inside the lesson JSON. Merge is PER FIELD: a missing `_es` falls back to
// English so a partial translation degrades gracefully instead of blanking a slide.
// `title` is deliberately excluded — `lesson.<id>.title` in en/es.json already owns it
// via t(..., {defaultValue: lesson.title}), and a title_es would silently lose to it.
const LOCALIZABLE_SUFFIX = '_es';

function pickLocalized(obj, key, locale) {
  if (locale !== 'es') return obj[key];
  const es = obj[`${key}${LOCALIZABLE_SUFFIX}`];
  return (typeof es === 'string' && es.length > 0) ? es : obj[key];
}

function stripEsKeys(obj) {
  const out = {};
  for (const [k, v] of Object.entries(obj)) {
    if (k.endsWith(LOCALIZABLE_SUFFIX)) continue;
    out[k] = v;
  }
  return out;
}

function localizeLesson(lesson, locale = 'en') {
  const slides = (lesson.slides ?? []).map((slide) => {
    const next = stripEsKeys(slide);
    next.infoProse = pickLocalized(slide, 'infoProse', locale);
    next.coachMessages = (slide.coachMessages ?? []).map((m) => {
      const nm = stripEsKeys(m);
      nm.text = pickLocalized(m, 'text', locale);
      nm.audio = pickLocalized(m, 'audio', locale);
      return nm;
    });
    next.legendItems = (slide.legendItems ?? []).map((li) => {
      const nl = stripEsKeys(li);
      nl.label = pickLocalized(li, 'label', locale);
      return nl;
    });
    return next;
  });

  const out = stripEsKeys(lesson);
  out.slides = slides;

  if (lesson.socratic) {
    const s = stripEsKeys(lesson.socratic);
    s.goalPrompt = pickLocalized(lesson.socratic, 'goalPrompt', locale);
    out.socratic = s;
  }
  if (Array.isArray(lesson.confirmationChallenges)) {
    out.confirmationChallenges = lesson.confirmationChallenges.map((c) => {
      const nc = stripEsKeys(c);
      nc.goalPrompt = pickLocalized(c, 'goalPrompt', locale);
      return nc;
    });
  }
  return out;
}
```

Then change the existing `getLesson(id)` to `getLesson(id, locale = 'en')` and return `localizeLesson(found, locale)` **after** its two existing backward-compat transforms (explicit-null `confirmationChallenges`, derived `confirmationCount`) so their behavior is preserved. Export `localizeLesson` alongside `getLesson`.

// D3: derive the badge from live /api/stripe/config so it can never drift from Stripe.
// Returns null (render nothing) rather than a misleading badge when prices are missing
// or annual isn't a saving — useStripePrices already degrades silently by design.
export function computeAnnualSavings(prices) {
  if (!prices) return null;
  const { monthly, annual } = prices;
  if (!monthly || !annual) return null;
  const yearlyAtMonthly = monthly * 12;
  if (annual >= yearlyAtMonthly) return null;
  return {
    percent: Math.round((1 - annual / yearlyAtMonthly) * 100),
    perMonth: Math.round(annual / 12),
  };
}
