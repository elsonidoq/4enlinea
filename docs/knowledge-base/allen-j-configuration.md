statement: |
  The J Configuration (also called J Shape) is a cluster of four Red discs at a
  specific L-shaped arrangement that generates a triple minor threat — three
  simultaneous winning continuations that make the position practically impossible
  to block. The canonical form is Red discs at {D1, D3, E2, E3}. From this base,
  Red threatens: (1) F3 via horizontal D3-E3-F3-G3; (2) G3 via diagonal continuation;
  (3) G4 via diagonal extension. These threats share the critical property that any
  Black response in one direction enables Red to pivot to another. The J Configuration
  is equivalent to a major odd-row threat and wins in zugzwang analysis. Mirror J
  (columns reflected) is equally valid.

short_summary: |
  A four-disc L-shaped Red cluster generating three simultaneous minor threats that
  is equivalent to a major odd-row threat; the opponent cannot block all three paths.

preconditions:
  - "Red owns four discs at cells {(x,y), (x,y+2), (x+1,y+1), (x+1,y+2)} for some (x,y) with y≥1."
  - "The extension cell (x+2, y+2) [horizontal threat target] is empty and not blocked by a Black disc in the same row."
  - "The diagonal extension cells (x+2, y+3) are on the board."
  - "y is odd (row y = odd, meaning the J's lower anchor is at an odd row — parity load-bearing)."

formal_predicate: |
  # J Configuration: Red owns (x,y), (x,y+2), (x+1,y+1), (x+1,y+2)
  # with the canonical anchor at (x,y) where y is odd.
  # Threats generated:
  #   T1: horizontal (x,y+2)-(x+1,y+2)-(x+2,y+2)-(x+3,y+2) → target (x+2,y+2) or (x+3,y+2)
  #   T2: diagonal ascending (x-1,y+1)-(x,y+2)-(x+1,y+3)... [depends on board]
  #   T3: diagonal from lower anchor

  def j_configuration(board, player, x, y, opponent_threats=None):
      # Canonical: (x,y) = lower-left anchor; y must be odd
      opponent = BLACK if player == RED else RED
      if opponent_threats is None:
          opponent_threats = []
      far_col = x + 2
      far_row = y + 2  # horizontal extension arm cell row
      # Parity cancellation: opponent has an odd-row threat in the far column
      opp_odd_in_far_col = any(
          t.col == far_col and t.row % 2 == 1
          for t in opponent_threats
      )
      return (
          y % 2 == 1                                  # parity load-bearing
          and board[x][y] == player                  # (x, y) = lower left
          and board[x][y+2] == player                # (x, y+2) = upper left
          and board[x+1][y+1] == player              # (x+1, y+1) = center right
          and board[x+1][y+2] == player              # (x+1, y+2) = upper right
          and x+3 <= 7                                # edge proximity: far column on board
          and board[far_col][far_row] != opponent    # overcutting: opponent not in far arm cell
          and not opp_odd_in_far_col                 # parity cancellation: no opponent odd-row threat in far column
      )

  # Mirror J (reflection about vertical axis):
  def mirror_j_configuration(board, player, x, y):
      # Reflected: (x,y), (x,y+2), (x-1,y+1), (x-1,y+2)
      return (
          y % 2 == 1
          and board[x][y] == player
          and board[x][y+2] == player
          and board[x-1][y+1] == player
          and board[x-1][y+2] == player
          and x-3 >= 1                            # horizontal extension on board
      )

  # Threat cells generated by canonical J:
  #   Primary horizontal threat: (x+2, y+2) — completes (x,y+2)-(x+1,y+2)-(x+2,y+2) with (x+3,y+2)
  #   Secondary diagonal threats: at (x+2, y+3) and/or (x+2, y+1) depending on board state

## Verbatim source

From Allen 2010, *The Complete Book of Connect 4*, Chapter 7, p. 117:

> The configuration shown in Diagram 63 is called the J shape because the four red disks form a shape like the letter J.
>
> When play goes up a column, the players take alternating cells (if there are no other tactical issues), so sooner or later Red must get either G3 or G4 in Diagram 63. In either case, F3 becomes a major threat, so it is easy to see that this triple threat is equivalent to a major odd-row threat.

From Allen 1990, *Expert Play in Connect-Four*, Glossary (hosted at tromp.github.io/c4.html):

> **J Configuration:** the common winning Eques configuration comprising D1-D3-E2-E3 or its mirror image.

Allen 2010 Diagram 63 movestring: `D1! d2 D3! el E2 d4 E3 (8)` with Black to play and lose.

## Notes

- **Two Allen sources:** "J Configuration" is from Allen 1990 (with formal D1-D3-E2-E3 coordinates); "J Shape" / "J-Shape Races" is from Allen 2010 Chapter 5 (which discusses the pattern in the context of racing to build the J). Both are canonical Allen terminology and mean the same pattern.
- **Triple threat mechanism:** From the J Configuration at {D1, D3, E2, E3}, Red's three threats share column F and G. If Black plays F3 (blocking the horizontal D3-E3-F3-?), Red has G4 available. If Black plays G4, Red has F3. If Black plays G3, Red has G4 and wins diagonally. The triple nature makes blocking impossible.
- **Canonical coordinates:** Allen 1990 defines the J Configuration as D1-D3-E2-E3 specifically (columns D=4, E=5; rows 1,2,3). Generalized by the formal predicate above to arbitrary (x,y) anchors with y odd.
