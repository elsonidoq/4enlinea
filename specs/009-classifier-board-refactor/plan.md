# Implementation Plan: Classifier Board Refactor

**Branch**: `009-classifier-board-refactor` | **Date**: 2026-05-26 | **Spec**: `specs/009-classifier-board-refactor/spec.md`

## Summary

Introduce a `Board` class as the single shared entry point for board-state access in
`classifier.js`, establish a layered primitive hierarchy (Layers 0–5), eliminate mutable
board mutation patterns by making threat-scanning functions mutation-free (exploiting the
fact that `checkWin` never reads `board[row][col]` itself), remove duplicated utilities
from `candidate-generator.js`, and add named T-rule predicates with KB-referenced JSDoc.
The external `classify()` signature is unchanged; all existing tests must pass at every
intermediate step.

## Board Class Design

```js
class Board {
  /**
   * Parses movestring once; all subsequent accesses read the cached state.
   * @complexity O(42)
   * @cache not cached (constructor)
   */
  constructor(movestring) {
    const { board, colHeights } = parseBoardState(movestring);
    this.movestring    = movestring;
    this.board         = board;          // board[row][col], row 0 = bottom
    this.colHeights    = colHeights;     // colHeights[col] = next empty row
    this.currentPlayer = movestring.length % 2 === 0 ? 1 : 2;
    this.opponent      = 3 - this.currentPlayer;
    this._cache        = new Map();
  }

  /**
   * Returns true if placing player at (row,col) completes four-in-a-row.
   * Delegates to free checkWin; does not read board[row][col].
   * @complexity O(1)
   * @cache not cached
   */
  checkWin(row, col, player) { return checkWin(this.board, row, col, player); }

  /**
   * Returns true if player already has four-in-a-row anywhere on the board.
   * @complexity O(42)
   * @cache cached per player
   */
  hasWon(player) {
    const key = `hasWon_${player}`;
    if (!this._cache.has(key)) this._cache.set(key, hasWon(this.board, player));
    return this._cache.get(key);
  }

  /**
   * Returns columns where player can win immediately (gravity-top cells only).
   * @complexity O(7)
   * @cache cached per player
   */
  immediateThreats(player) {
    const key = `immediateThreats_${player}`;
    if (!this._cache.has(key)) this._cache.set(key, getImmediateThreats(this.board, this.colHeights, player));
    return this._cache.get(key);
  }

  /**
   * Returns Map<col, row[]> of all empty cells at or above colHeight where player wins.
   * @complexity O(42)
   * @cache cached per player
   */
  reachableThreats(player) {
    const key = `reachableThreats_${player}`;
    if (!this._cache.has(key)) this._cache.set(key, getReachableThreats(this.board, this.colHeights, player));
    return this._cache.get(key);
  }

  /**
   * Returns all 4-cell windows completed by placing player at (row,col).
   * @complexity O(16) — 4 directions × 4 offsets
   * @cache not cached (varies by row/col)
   */
  winningWindows(row, col, player) { return getWinningWindows(this.board, row, col, player); }

  /**
   * Returns the full major-threat map for all empty cells on the board.
   * @complexity O(672) — 42 cells × 4 directions × 4 offsets
   * @cache cached (player-independent)
   */
  majorThreatCells() {
    if (!this._cache.has('majorThreatCells')) this._cache.set('majorThreatCells', getMajorThreatCells(this.board));
    return this._cache.get('majorThreatCells');
  }

  /**
   * Returns true if player has an active double threat (≥2 immediate wins, or 1 immediate
   * win with a major threat stacked above it in the same column).
   * @complexity O(7) + O(672) on first call
   * @cache cached per player
   */
  hasActiveDoubleThreat(player) {
    const key = `hasActiveDoubleThreat_${player}`;
    if (!this._cache.has(key)) this._cache.set(key, hasActiveDoubleThreat(this.board, this.colHeights, player));
    return this._cache.get(key);
  }

  /**
   * Returns a new Board for the position after placing in col. Starts with empty cache.
   * @complexity O(42) — re-parses full movestring
   * @cache not cached
   * @throws RangeError if col is out of range or the column is full
   */
  withMove(col) {
    if (col < 0 || col >= COLS || this.colHeights[col] >= ROWS) {
      throw new RangeError(`withMove: column ${col} is full or out of range`);
    }
    return new Board(this.movestring + col.toString());
  }
}
```

### Cache invariant

> Every cached value on a `Board` instance equals the result of calling the corresponding
> free function with the raw `board` and `colHeights` arrays produced by parsing
> `this.movestring` from scratch.

Maintained by:
1. Lazy write-once populate: cache entries are set once and never updated.
2. `Board` immutability: no method mutates `this.board`, `this.colHeights`, or `this._cache` after construction.
3. `withMove` creates a new Board: simulation never mutates the original.

## Mutation-free threat scanning

The key insight that eliminates all mutation+undo patterns in the free functions:

`checkWin(board, row, col, player)` starts `count = 1` (the placed piece) and reads only
`board[r±dr][c±dc]` for `d = 1..3`. It **never reads `board[row][col]`**. Therefore calling
it on an empty cell correctly answers "would placing `player` here win?" without placing the
piece first.

This means `getImmediateThreats` and `getReachableThreats` require **no board mutation**:

```js
// getImmediateThreats — O(7), mutation-free
export function getImmediateThreats(board, colHeights, player) {
  const cols = [];
  for (let col = 0; col < COLS; col++) {
    const row = colHeights[col];
    if (row >= ROWS) continue;
    if (checkWin(board, row, col, player)) cols.push(col);
  }
  return cols;
}
```

`hasActiveDoubleThreat` is similarly rewritten without mutation:

```js
export function hasActiveDoubleThreat(board, colHeights, player) {
  const winCols = getImmediateThreats(board, colHeights, player);
  if (winCols.length >= 2) return true;
  if (winCols.length === 1) {
    const c = winCols[0];
    const r = colHeights[c];
    if (r + 1 < ROWS) {
      const t = getMajorThreatCells(board)[`${r+1},${c}`];
      if (t && (player === 1 ? t.rm : t.ym)) return true;
    }
  }
  return false;
}
```

`getWinningWindows` was already mutation-free (reads only; the placed piece is not
verified at board[threatRow][threatCol]).

## `getReachableThreats` specification

```js
/**
 * Returns a Map from column to the rows in that column where placing player would win.
 * Only considers cells at or above colHeights[col] (empty cells reachable by gravity).
 * Cells below colHeights[col] are occupied by construction; they are never included.
 * Calls checkWin without mutation — see research.md Decision 1.
 * @param {number[][]} board
 * @param {number[]} colHeights
 * @param {number} player  1 or 2
 * @returns {Map<number, number[]>}  Map<col, row[]>, rows in ascending order
 * @complexity O(42)
 * @cache cached per player on Board instances
 */
export function getReachableThreats(board, colHeights, player) {
  const result = new Map();
  for (let col = 0; col < COLS; col++) {
    const rows = [];
    for (let row = colHeights[col]; row < ROWS; row++) {
      if (checkWin(board, row, col, player)) rows.push(row);
    }
    if (rows.length > 0) result.set(col, rows);
  }
  return result;
}
```

**Return shape**: `Map<col, row[]>`. Columns with no winning cells are absent (not in the
Map). Rows within each column are in ascending order (bottom-to-top iteration order).

**Replaces**: The duplicated `for (let row = 0; row < ROWS; row++) { if (board[row][col] !== 0) continue; board[row][col] = player; if (checkWin(...)) ...; board[row][col] = 0; }` loops in `detectUndercut`, `detectOvercut`, `detectFigure7`, and `detectJShape`.

**Usage in detectUndercut / detectOvercut**:
```js
const threats    = board.reachableThreats(board.currentPlayer);  // Map
const oppThreats = board.reachableThreats(board.opponent);       // Map (cached from prior call or first)
const colRows    = threats.get(col) ?? [];
const oppRows    = oppThreats.get(col) ?? [];
```

**Usage in detectFigure7 / detectJShape**:
These detectors need threats AFTER placing `comp.col`. They call
`nextBoard.reachableThreats(board.currentPlayer)` on a `withMove` result, not directly
on the pre-move board.

## T-rule predicates

All rows are **0-indexed** throughout. Allen's source text uses 1-indexed rows; the
translation is applied once at the KB boundary (noted in each JSDoc with concrete values).

### `isT4SameParity`

```js
/**
 * Returns true when two same-column threats have the same row parity.
 * T4: same parity → no interaction between threats, regardless of player.
 * 0-indexed rows: even ↔ Allen 1-indexed odd; odd ↔ Allen 1-indexed even.
 * Parity condition is preserved across the translation (same%2 ↔ same%2).
 * @param {number} R   current player's threat row (0-indexed)
 * @param {number} Rp  opponent's threat row (0-indexed)
 * @returns {boolean}
 * @see allen-t4
 */
export function isT4SameParity(R, Rp) {
  return R % 2 === Rp % 2;
}
```

### `isT5Exception`

```js
/**
 * Returns true for the specific row pair (0-indexed 5, 2) = Allen rows (6, 3).
 * T5 overrides T2 for this pair: threats at Allen rows 3 and 6 in the same column
 * do NOT interact despite opposite parity. Rows 5+2 (0-indexed) = rows 6+3 (Allen).
 * @param {number} R   (0-indexed row)
 * @param {number} Rp  (0-indexed row)
 * @returns {boolean}
 * @see allen-t5
 */
export function isT5Exception(R, Rp) {
  return (R === 5 && Rp === 2) || (R === 2 && Rp === 5);
}
```

### `isT2Blocking`

```js
/**
 * Returns true if a current-player threat at Rpp < Rp (0-indexed) neutralizes the
 * opponent's threat at Rp via T2 (cross-parity undercut).
 *
 * Sub-case 2: CP threat at even 0-indexed row below opponent's odd 0-indexed row,
 *   any distance. (CP even 0-indexed = CP odd Allen; opp odd 0-indexed = opp even Allen.)
 * Sub-case 3: CP threat at odd 0-indexed row immediately below opp even 0-indexed row
 *   (Rpp + 1 === Rp). Adjacent-only restriction — see T2 known_limitations.
 *
 * @param {number[]} colThreats  Current-player threat rows in this column (0-indexed)
 * @param {number}   R           Current player's upper threat row (R > Rp, 0-indexed)
 * @param {number}   Rp          Opponent's threat row (0-indexed)
 * @returns {boolean}
 * @see allen-t2
 */
export function isT2Blocking(colThreats, R, Rp) {
  return colThreats.some(Rpp => {
    if (Rpp >= Rp) return false;
    if (Rpp % 2 === 0 && Rp % 2 === 1) return true; // sub-case 2: CP even, opp odd, any distance
    if (Rpp % 2 === 1 && Rp % 2 === 0 && Rpp + 1 === Rp) return true; // sub-case 3: adjacent
    return false;
  });
}
```

### Guard equivalence verification

The three predicates together must produce identical guard outcomes to the current inline
code. The table below cross-references each guard with its named replacement:

| Detector | Guard name | Current inline condition | Named predicate |
|---|---|---|---|
| detectUndercut | U1 | `R % 2 === kill % 2` | `isT4SameParity(R, kill)` |
| detectUndercut | U2 | `R === 5 && kill === 2` | `isT5Exception(R, kill)` |
| detectUndercut | U3 | `R % 2 === 1 && kill % 2 === 0 && R !== kill + 1` | sub-case 3 adjacency check inline (see §detectUndercut migration) |
| detectOvercut | O1 | `sameParity \|\| t5Exception \|\| chainT2` | `isT4SameParity(R,Rp) \|\| isT5Exception(R,Rp) \|\| isT2Blocking(colRows, R, Rp)` |

Note: U3 is NOT replaced by `isT2Blocking`. `detectUndercut` guards are `continue` (skip when condition holds); U3 says skip if T2 sub-case 3 would require adjacency but rows are NOT adjacent. This is the inverse of `isT2Blocking`'s sub-case 3. The inline expression stays for clarity.

## detectUndercut migration

**Before** (current):
```js
export function detectUndercut(moves, scores) {
  const moveCount = moves.length;
  const { board, colHeights } = parseBoardState(moves);
  const currentPlayer = (moveCount % 2 === 0) ? 1 : 2;
  const opponent = 3 - currentPlayer;

  const currentThreats = {};
  const opponentThreats = {};
  for (let col = 0; col < COLS; col++) {
    currentThreats[col] = [];
    opponentThreats[col] = [];
    for (let row = 0; row < ROWS; row++) {
      if (board[row][col] !== 0) continue;
      board[row][col] = currentPlayer;
      if (checkWin(board, row, col, currentPlayer)) currentThreats[col].push(row);
      board[row][col] = 0;
      board[row][col] = opponent;
      if (checkWin(board, row, col, opponent)) opponentThreats[col].push(row);
      board[row][col] = 0;
    }
  }

  for (let col = 0; col < COLS; col++) {
    if (colHeights[col] >= ROWS) continue;
    if (!scores || scores[col] >= 0) continue;
    for (const R of currentThreats[col]) {
      const kill = opponentThreats[col].find(rp => rp < R);
      if (kill === undefined) continue;
      if (R % 2 === kill % 2) continue;                          // U1
      if (R === 5 && kill === 2) continue;                       // U2
      if (R % 2 === 1 && kill % 2 === 0 && R !== kill + 1) continue; // U3
      return { matched: true, highlightMetadata: ..., categoryEvidence: {} };
    }
  }
  return { matched: false };
}
```

**After** (refactored):
```js
export function detectUndercut(board, scores) {
  // @see allen-t4, allen-t5, allen-t2
  const threats    = board.reachableThreats(board.currentPlayer); // Map<col, row[]>
  const oppThreats = board.reachableThreats(board.opponent);      // cached if already called

  for (let col = 0; col < COLS; col++) {
    if (board.colHeights[col] >= ROWS) continue;
    if (!scores || scores[col] >= 0) continue;
    const colRows    = threats.get(col) ?? [];
    const oppColRows = oppThreats.get(col) ?? [];

    for (const R of colRows) {
      const kill = oppColRows.find(rp => rp < R);
      if (kill === undefined) continue;
      if (isT4SameParity(R, kill)) continue;                            // U1 @see allen-t4
      if (isT5Exception(R, kill)) continue;                             // U2 @see allen-t5
      if (R % 2 === 1 && kill % 2 === 0 && R !== kill + 1) continue;   // U3 @see allen-t2 sub-case 3
      return {
        matched: true,
        highlightMetadata: {
          type: 'cells',
          cells: [
            { column: col, row: kill, role: 'killing_threat' },
            { column: col, row: R,    role: 'dead_threat' },
          ],
        },
        categoryEvidence: {},
      };
    }
  }
  return { matched: false };
}
```

**Guard identity**: U1 and U2 are direct named replacements. U3 stays inline because
`isT2Blocking` tests `Rpp < Rp` (a third threat below the opponent's threat), whereas U3
tests the pair (R, kill) directly for the adjacency property. The inline expression and
the pre-existing comment are sufficient documentation for U3.

## detectFigure7 migration

The current `detectFigure7` has two mutation sites that are eliminated:
1. **Outer mutation** — places `currentPlayer` at `comp` and increments `colHeights[comp.col]` to simulate the completing move, then undoes both at the end of each template iteration.
2. **Inner mutation loop** — for each reachable cell `(row, col)` it places `currentPlayer`, calls `checkWin`, removes the piece, then calls `getWinningWindows` on the un-mutated board.

Both are replaced by `board.withMove(comp.col)` (outer) and `nextBoard.reachableThreats(currentPlayer)` (inner).

**Before** (current — mutation sites marked):

```js
export function detectFigure7(board, scores) {
  const currentPlayer = board.currentPlayer;

  for (let x = 0; x < COLS; x++) {
    for (let y = 0; y < ROWS; y++) {
      // ... build variants (unchanged) ...
      for (const template of variants) {
        const comp = template[2];
        const placed = template.filter((_, i) => i !== 2);

        if (!placed.every(c => board.board[c.row][c.col] === currentPlayer)) continue;
        if (board.board[comp.row][comp.col] !== 0) continue;
        if (board.colHeights[comp.col] !== comp.row) continue;
        if (!scores || scores[comp.col] <= 0) continue;

        const nextBoard = board.withMove(comp.col);  // replaces outer mutation+undo; throws never (colHeights guard above)
        const templateSet = new Set([...placed, comp].map(c => `${c.row},${c.col}`));

        const threatCells = [];
        // nextBoard.reachableThreats replaces the inner mutation loop:
        // it iterates from nextBoard.colHeights[col] upward and calls checkWin without placement.
        for (const [col, rows] of nextBoard.reachableThreats(currentPlayer)) {
          for (const row of rows) {
            // nextBoard.winningWindows does not read (row,col) itself — identical to the old
            // getWinningWindows(board, row, col, player) call made after board[row][col] = 0.
            const windows = nextBoard.winningWindows(row, col, currentPlayer);
            if (windows.some(w => w.filter(cell => templateSet.has(`${cell.row},${cell.col}`)).length >= 3)) {
              threatCells.push({ column: col, row });
            }
          }
        }

        if (threatCells.length < 2) continue;
        // nextBoard.colHeights has comp.col already incremented — same values the old mutated
        // colHeights[] had when gravityTopCount/hasAboveGravity/hasConsecutivePair were computed.
        const gravityTopCount = threatCells.filter(t => t.row === nextBoard.colHeights[t.column]).length;
        const hasAboveGravity = threatCells.some(t => t.row > nextBoard.colHeights[t.column]);
        if (gravityTopCount >= 2) continue;
        if (!hasAboveGravity) continue;
        const hasConsecutivePair = threatCells.some(t1 =>
          threatCells.some(t2 =>
            t2.column === t1.column &&
            t2.row === t1.row + 1 &&
            t1.row <= nextBoard.colHeights[t1.column] + 1
          )
        );
        if (!hasConsecutivePair) continue;

        return {
          matched: true,
          highlightMetadata: {
            type: 'cells',
            cells: placed.map(c => ({ column: c.col, row: c.row, role: 'pattern_piece' })),
          },
          correctCol: comp.col,
          categoryEvidence: {
            pattern_cells: placed.map(c => ({ column: c.col, row: c.row })),
            threat_cells: threatCells,
          },
        };
      }
    }
  }
  return { matched: false };
}
```

**Key behavioral identities**:
- `nextBoard.colHeights[comp.col]` equals the old `colHeights[comp.col]` after the outer `colHeights[comp.col]++`.
- `nextBoard.reachableThreats(currentPlayer)` iterates from `nextBoard.colHeights[col]` upward calling `checkWin` without placement — identical to the old inner loop that placed then removed the piece (since `checkWin` never reads `board[row][col]` itself).
- `nextBoard.winningWindows(row, col, currentPlayer)` = `getWinningWindows(nextBoard.board, row, col, currentPlayer)`. `nextBoard.board[comp.row][comp.col] === currentPlayer` (comp was placed), which is the same state the old `board` was in when `getWinningWindows` was called (after the inner undo `board[row][col] = 0` but with the outer comp piece still in place).
- `gravityTopCount`, `hasAboveGravity`, and `hasConsecutivePair` all use `nextBoard.colHeights` — same values as the old mutated `colHeights[]`.

## classify() migration

`classify()` constructs one Board and uses `withMove` for all hypothetical placements:

```js
export function classify(moves, candidateCol, scores) {
  const board = new Board(moves);
  const score = scores[candidateCol];

  // Cat 1: Immediate Threat
  if (board.colHeights[candidateCol] < ROWS) {
    const row = board.colHeights[candidateCol];
    if (board.withMove(candidateCol).checkWin(row, candidateCol, board.currentPlayer)) {
      return { tag: 'immediate_threat' };
    }
  }

  // Cat 3: Double Threat
  if (board.colHeights[candidateCol] < ROWS) {
    const nextBoard = board.withMove(candidateCol);
    const threatCells = [];
    for (const [col, rows] of nextBoard.reachableThreats(board.currentPlayer)) {
      for (const row of rows) threatCells.push({ col, row });
    }

    // Case A: ≥2 distinct columns with a gravity-top threat
    const gravityTopCols = new Set(
      threatCells.filter(t => t.row === nextBoard.colHeights[t.col]).map(t => t.col)
    );
    if (gravityTopCols.size >= 2) return { tag: 'double_threat' };

    // Case B: consecutive-row threats in same column
    const byCol = {};
    for (const t of threatCells) {
      if (!byCol[t.col]) byCol[t.col] = [];
      byCol[t.col].push(t.row);
    }
    for (const rows of Object.values(byCol)) {
      const sorted = rows.sort((a, b) => a - b);
      for (let i = 0; i < sorted.length - 1; i++) {
        if (sorted[i + 1] === sorted[i] + 1) return { tag: 'double_threat' };
      }
    }
  }

  // Cat 2: Forced Block
  if (score >= 0) {
    const opponent = board.opponent;
    if (board.immediateThreats(opponent).length > 0) {
      const nextBoard = board.withMove(candidateCol);
      if (nextBoard.immediateThreats(opponent).length === 0) {
        const someOtherFails = scores.some((_, i) => {
          if (i === candidateCol || board.colHeights[i] >= ROWS) return false;
          return board.withMove(i).immediateThreats(opponent).length > 0;
        });
        if (someOtherFails) return { tag: 'forced_block' };
      }
    }
  }

  // Cat 4: Forced Win (score-only, no board)
  if (score < 0) {
    const allNegative = scores.every(s => s <= 0);
    const isBestBadMove = scores.every(s => s <= score || s === 0);
    if (allNegative && isBestBadMove && scores.some(s => s < score)) {
      return { tag: 'forced_win' };
    }
  }

  // Cat 5: Forbidden Column
  if (scores.every(s => s <= 0) && board.colHeights[candidateCol] < ROWS) {
    if (board.withMove(candidateCol).immediateThreats(board.opponent).length > 0) {
      return { tag: 'forbidden_columns' };
    }
  }

  if (score > 0) return { tag: 'best_move' };
  if (score === 0) return { tag: 'drawing_move' };
  return { tag: 'suboptimal_move' };
}
```

No `parseBoardState` calls remain inside `classify()`. The single `new Board(moves)` call
satisfies SC-002.

**withMove call count per classify() invocation** (worst case):
- Cat 1: 1
- Cat 3: 1
- Cat 2: 1 (nextBoard) + up to 6 (someOtherFails loop) = 7
- Cat 5: 1
- Total: ≤ 10, each O(42) = O(420) total. Negligible compared to solver queries.

## withMove performance

`withMove(col)` appends one character to `this.movestring` and constructs `new Board(...)`,
which calls `parseBoardState`. `parseBoardState` iterates over at most 42 characters —
O(42).

**Current callers in classify()**: at most 10 per call (see §classify() migration). Combined cost: O(420). Negligible relative to any solver query (≥ 100ms).

**Current callers in detectFigure7**: at most one `withMove` per matching template, in
practice 0–3 per detectFigure7 invocation. Not a tight loop.

**No other detector calls withMove**: `detectZThreat`, `detectUndercut`, `detectOvercut`,
`detectJShape`, and `detectClaimeven` use `board.reachableThreats()` directly without
withMove. `detectJShape` checks patterns on the un-moved board using `board.board` and
`board.colHeights` with direct `checkWin` calls (mutation-free).

**Conclusion**: O(42) per withMove is acceptable for the current workload. No optimization
is in scope. If profiling ever shows it matters, `withMove` can accept a pre-built state
object to do a copy-and-increment instead of re-parsing; this is a backward-compatible
internal change.

## Board Class

`Board` in `classifier.js` is the standard entry point for board-state access in the
classifier and detectors. Construct it once per position; pass it to all consumers.

**MUST** use `new Board(movestring)` in `classify()` and all `detect*` functions.
**MUST NOT** call `parseBoardState` inside `classify()` or `detect*` functions; use
`board.board` / `board.colHeights` / board methods instead.

`parseBoardState` remains a free export for callers that need mutable raw arrays
(simulation loops, one-shot predicate checks that do not share state across detectors).

`board.withMove(col)` returns a new immutable `Board` for the position after placing in
`col`. Use it instead of the mutation+undo pattern (`board[r][c] = player; ...; board[r][c] = 0`).
The mutation+undo pattern MUST NOT appear in `classify()` or any `detect*` function.
