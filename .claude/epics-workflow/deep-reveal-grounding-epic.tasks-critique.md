## Decisions required

**A. Does an offered `windows:`/`cells:` alias admit each of its cells individually, or only the full window as a unit?**
This is `toAllowedSet`'s mapping semantics (T029) and, per data-model.md §3, "the only part with real design content." T029 sets the default to per-cell admission but says "revisit this default against the four staging boards during T032" — and T032 is the wrong task (see blocking issue 1), so as written it is never revisited and ships unexamined.
- *Option 1 (recommended)*: keep per-cell admission. Mirrors `checkP5Strong`'s existing `cells:` branch, which already treats a multi-cell spec as a set of individually-admissible cells. Fold the revisit into the new staging-board acceptance task.
- *Option 2*: whole-window-only. Stricter grounding, but it would reject a coach highlight of one cell of a window the engine *did* offer — a false rejection that `stripFailingZoneSpans` would now actually strip (T027 adds `P5strong` to `SPAN_CARRYING_CODES`), degrading real explanations.

**B. Which nested-promotion guard does `promoteRawCoordinates` use, and who picks it?**
data-model.md §5 leaves this genuinely open ("**UNVERIFIED SKETCH — adapt**"): a `cXrY` sitting inside an *existing* zone's inner text (`[zone:c4r1]watch c4r1 closely[/zone:c4r1]`) must not be re-wrapped, and splitting on `ZONE_TAG_RE` does not solve it because an open zone's inner text is itself an even-indexed segment. T028 defers the choice to implementation time and T026 case 3 says the test "must cover the resolution." If T026 and T028 are executed by different agents, they will pick differently and the test will encode the wrong shape.
- *Option 1 (recommended)*: track open/close zone depth across segments and skip promotion while depth > 0 — decide it now, write it into both T028 and T026 case 3, and mark the two tasks as must-be-same-agent/same-commit (same treatment T025/T027 already got).
- *Option 2*: restrict promotion to net-zero-depth segments. Simpler to state, but silently skips promotion in a segment containing both an opened and a closed zone.
