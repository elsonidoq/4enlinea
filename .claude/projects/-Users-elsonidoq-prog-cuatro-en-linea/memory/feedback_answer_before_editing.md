When the user asks a question, answer it first before editing files or running tools.

**Why:** User explicitly requested this — jumping straight to edits without answering the question is unhelpful.

**How to apply:** Any time a user message is phrased as a question, respond with the answer in text first. Only then proceed with any file edits or tool calls if action is also needed.
