# MVP Launching Tactic Structure

## 1. Launch Objective
- Define the single outcome the launch must validate.
- Examples:
  - Demand exists
  - Users retain after first week
  - Free users convert to paid
  - Core feature solves a real pain point

## 2. Launch Hypothesis
- If we launch **[product]** to **[specific audience]** with **[core value proposition]**, then **[measurable result]** will happen within **[timeframe]**.

## 3. Narrow Initial Audience
- Define the smallest high-intent segment.
- Existing communities where they already gather.
- Why they feel pain strongly enough to try something new.

## 4. Core Offer at Launch
- What users get immediately.
- Only the features required to create a “this is useful” moment.
- Remove all extras not tied to validation.

## 5. Positioning & Messaging
- What problem it solves.
- Why current alternatives fail.
- Why this product is different now.
- One clear promise.

## 6. Acquisition Channels (Ranked)
For each channel:
- Audience match
- Speed to test
- Cost
- Credibility

Typical channels:
- Niche communities
- Reddit / Discord / Forums
- Direct outreach
- SEO landing page
- Partnerships / influencers
- Paid ads

## 7. Pre-Launch Setup
- Landing page
- Waitlist capture
- Demo / screenshots / short video
- Analytics events
- Pricing page
- Email collection sequence

## 8. Launch Mechanics
### Soft Launch
- Small controlled user group first.
- Collect bugs, confusion points, onboarding failures.

### Public Launch
- Announce where target users already are.
- Use testimonials / proof / demos.
- Clear CTA.

## 9. Onboarding Flow
- Time to first value must be minimal.
- Remove account creation friction if possible.
- Guide user into first success moment fast.

## 10. Conversion Trigger
- Define what free users naturally want next.
- Paywall should appear after value is experienced.
- Paid tier must compound usefulness over time.

## 11. Retention Loop
- Why users return weekly.
- Habit tied to real progress, not gimmicks.
- Examples:
  - New challenges
  - Personalized feedback
  - Progress tracking
  - Review system

## 12. Metrics Dashboard
### Acquisition
- Visits
- Signup rate
- CAC / CPI

### Activation
- % reaching first value moment
- Time to first success

### Retention
- D1 / D7 / D30 retention
- Weekly active users

### Revenue
- Trial start rate
- Free-to-paid conversion
- Churn

## 13. Feedback Capture System
- User interviews
- Exit surveys
- Session recordings
- Support messages
- Community comments

Focus on repeated complaints, not one-off noise.

## 14. 30-Day Iteration Plan
Week 1:
- Fix onboarding friction

Week 2:
- Improve retention loop

Week 3:
- Improve conversion points

Week 4:
- Double down on best acquisition channel

## 15. Kill / Scale Decision Rules
### Scale If:
- Strong retention
- Users recommend it
- Paid conversion proves willingness to pay

### Pivot If:
- Interest high, retention weak
- Usage high, conversion weak

### Kill If:
- Low demand + low retention after honest iteration
